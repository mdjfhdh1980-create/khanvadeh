# پیام‌رسان خانواده

نسخه‌ی واقعی اولیه با Node.js، Express و Socket.IO.

## اجرا
1. Node.js نصب باشد.
2. داخل پوشه پروژه اجرا کنید:
   npm install
   npm start
3. مرورگر را روی http://localhost:3000 باز کنید.
4. هر عضو خانواده یک حساب بسازد.
5. برای استفاده از گوشی‌های مختلف، همین پروژه باید روی یک سرور/هاست آنلاین اجرا شود.

اطلاعات کاربران و پیام‌ها در data.json ذخیره می‌شوند. برای استفاده عمومی بهتر است قبل از انتشار، دیتابیس واقعی، HTTPS، مدیریت نشست و ذخیره‌سازی امن فایل‌ها اضافه شود.
